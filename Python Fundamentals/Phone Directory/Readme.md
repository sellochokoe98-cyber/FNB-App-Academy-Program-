# 📞 Phone Directory

## 📌 Project Overview
The **Phone Directory** is a simple Python command-line application developed as part of the **FNB App Academy – Introduction to Python Coding** program. It allows users to store, search, update, and manage contact information using Python data structures.

## 🎯 Objectives
- Practice working with dictionaries.
- Learn how to store and retrieve data.
- Apply loops and conditional statements.
- Build an interactive menu-driven application.

## ✨ Features
- Add a new contact
- Search for a contact by name
- Display all contacts
- Update existing contact details
- Delete a contact
- Exit the application

## 🛠️ Technologies Used
- Python 3
