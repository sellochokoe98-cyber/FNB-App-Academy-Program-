# Command-Line Contact Book

A simple Python command-line application developed as part of the **FNB App Academy – Introduction to Python Coding** program. The application allows users to store and manage contact information using a text-based interface.

## 📌 Project Overview

This project demonstrates how to create a basic contact management system where users can add, search, view, and delete contacts using Python.

## ✨ Features

- Add new contacts
- View all saved contacts
- Search for a contact by name
- Delete contacts
- Simple command-line interface
- Uses lists and dictionaries for data storage

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
command_line_contact_book.py
README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python command_line_contact_book.py
```

4. Follow the on-screen menu to manage your contacts.
