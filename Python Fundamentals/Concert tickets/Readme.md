# Concert Ticket Booking

A simple Python application developed as part of the **FNB App Academy – Introduction to Python Coding** program. The application simulates a concert ticket booking system where users can purchase tickets and receive a booking confirmation.

## 📌 Project Overview

This project demonstrates how Python can be used to collect user information, validate input, calculate ticket costs, and generate a booking summary.

## ✨ Features

- Enter customer details
- Select the number of tickets
- Calculate the total ticket price
- Display a booking confirmation
- Validate user input

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
concert_ticket_booking.py
README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python concert_ticket_booking.py
```

4. Enter your booking details when prompted.
5. Review the booking summary and total cost.
