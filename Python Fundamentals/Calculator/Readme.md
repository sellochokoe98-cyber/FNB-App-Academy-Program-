# Calculator

A simple command-line calculator developed in Python as part of the FNB App Academy Introduction to Python Coding program.

## 📌 Project Overview

This application allows users to perform basic arithmetic calculations by entering two numbers and selecting a mathematical operation.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles invalid operators
- Prevents division by zero

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
calculator.py
README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python calculator.py
```

4. Enter two numbers.
5. Choose an operation (+, -, *, /).
6. View the result.
