# Security Password Hint Tool

A simple Python application developed as part of the **FNB App Academy – Introduction to Python Coding** program. The program generates a secure password hint based on user input without revealing the actual password.

## 📌 Project Overview

This project demonstrates how Python can process strings and create helpful password hints while encouraging secure password practices.

## ✨ Features

- Accepts a user-created password
- Generates a password hint
- Uses string manipulation techniques
- Helps protect the actual password from being displayed

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
security_password_hint.py
README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python security_password_hint.py
```

4. Enter your password.
5. The program displays a password hint instead of the full password.
