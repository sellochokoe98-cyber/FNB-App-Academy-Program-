# 👨‍🎓 Student Information

## 📌 Project Overview
The **Student Information** project is a simple Python program developed as part of the **FNB App Academy – Introduction to Python Coding** program. It collects a student's details, stores them in variables, and displays the information in a clear, formatted output.

## 🎯 Objectives
- Learn how to use variables.
- Practice accepting user input.
- Display formatted output.
- Understand basic Python syntax.

## ✨ Features
- Enter student name
- Enter surname
- Enter age
- Enter student number
- Enter course name
- Display all student information in a readable format

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run:

```bash
python student_information.py
```

## 💻 Example Output
```
===== STUDENT INFORMATION =====
Name: John
Surname: Doe
Age: 21
Student Number: 12345678
Course: Introduction to Python
```

## 📚 Skills Demonstrated
- Variables
- User Input (`input()`)
- String Formatting
- Print Statements
- Basic Python Programming

## 🚀 Learning Outcomes
This project helped me understand how to collect, store, and display user information using Python. It strengthened my knowledge of variables, user input, and formatted output while building confidence in creating simple command-line applications.
