# Loop Repeats

A simple Python project developed as part of the **FNB App Academy – Introduction to Python Coding** program. This application demonstrates how loops can be used to repeat tasks until a specific condition is met.

## 📌 Project Overview

This project introduces repetition in Python using loops. It allows users to perform actions multiple times without rewriting code, making programs more efficient and interactive.

## ✨ Features

- Repeats tasks automatically
- Accepts user input inside a loop
- Continues until an exit condition is met
- Demonstrates `while` and/or `for` loops

## 🛠️ Technologies Used

- Python 3
