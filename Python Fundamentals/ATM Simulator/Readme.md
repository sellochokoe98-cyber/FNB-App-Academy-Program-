# 🏧 ATM Simulator

## 📌 Project Overview
The ATM Simulator is a Python command-line application developed as part of the **FNB App Academy – Introduction to Python Coding** program. It simulates the basic functions of an Automated Teller Machine (ATM), allowing users to perform simple banking transactions through a menu-driven interface.

## 🎯 Objectives
- Practice Python programming fundamentals.
- Apply conditional statements and loops.
- Work with variables, user input, and functions.
- Simulate real-world banking operations.

## ✨ Features
- Secure PIN verification
- View account balance
- Deposit money
- Withdraw money
- Exit the application
- Prevent withdrawals that exceed the available balance

## 🛠️ Technologies Used
- Python 3
