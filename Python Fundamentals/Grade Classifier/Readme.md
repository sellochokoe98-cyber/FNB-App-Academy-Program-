# 📊 Grade Report / Grade Classifier

## 📌 Project Overview
The **Grade Report / Grade Classifier** is a Python command-line application developed as part of the **FNB App Academy – Introduction to Python Coding** program. It accepts a student's marks, calculates the result, and classifies the final grade based on predefined grading criteria.

## 🎯 Objectives
- Practice using conditional statements.
- Work with user input and variables.
- Learn decision-making in Python.
- Display meaningful results based on student marks.

## ✨ Features
- Enter student name
- Enter student marks
- Classify grades (A, B, C, D, F or equivalent)
- Display pass or fail status
- Generate a simple grade report
- Validate user input

## 🛠️ Technologies Used
- Python 3

## 📂 Project Structure

Grade_Report/

## ▶️ How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run:

```bash
python grade_report.py
```
