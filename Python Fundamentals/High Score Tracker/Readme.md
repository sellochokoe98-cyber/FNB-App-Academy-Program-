# 🏆 High Score Tracker

## 📌 Project Overview
The **High Score Tracker** is a simple Python command-line application developed as part of the **FNB App Academy – Introduction to Python Coding** program. The application allows users to enter player names and scores, compares them to the current highest score, and keeps track of the top-performing player.

## 🎯 Objectives
- Practice using variables and user input.
- Apply conditional statements.
- Work with loops to process multiple entries.
- Learn how to compare and update values.

## ✨ Features
- Enter player names
- Enter player scores
- Track the highest score
- Display the player with the highest score
- Allow multiple score entries
- Exit the application

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run:

```bash

```
