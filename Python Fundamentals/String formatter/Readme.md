# String Formatter

A simple Python application developed as part of the **FNB App Academy – Introduction to Python Coding** program. The application formats user-provided text into a clean and readable output using Python string operations.

## 📌 Project Overview

This project demonstrates how to manipulate and format strings in Python by accepting user input and displaying it in a structured format.

## ✨ Features

- Accepts user input
- Formats text for improved readability
- Uses string methods such as `upper()`, `lower()`, and `title()`
- Displays neatly formatted output

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python string_formatter.py
```

4. Enter the requested information.
5. View the formatted output.
